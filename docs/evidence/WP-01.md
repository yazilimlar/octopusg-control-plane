## Method

The Mac checkout was read through the Cowork file bridge (no shell on the Mac in this session).
All non-dependency files and every loose Git object were copied to an isolated cloud workspace;
Git state was reconstructed there and matched the reported state exactly. All commands below
ran on that copy (Node 22.22 with type stripping; the package declares Node 24). The bridge
refuses writes inside `.git`, so the commit was delivered to the Mac as a self-contained Git
bundle in the ignored `work/wp-01/` folder; the owner applies it with `git fetch` and
`git switch`, and Git writes the objects, index and working tree itself.
