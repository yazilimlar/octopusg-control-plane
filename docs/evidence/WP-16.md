## Scope and authority

This package is authorized by [S10](../sources/S10-2026-09-21-owner-wp16-authorization.md).
It implements the provider-neutral `CredentialRef → CredentialProvider → secure backing store`
boundary and the generic connector security precondition only. The macOS Keychain provider is a
fail-closed adapter with no real store access. Supabase, DayOS, `OG-CONN-015`, its ADR and G3
authorization are explicitly outside this package.

## Implementation

- `src/credentials.ts` validates and freezes a bounded non-secret provider reference and exposes
  an opaque provider callback contract. It contains no filesystem, process, network or Keychain access.
- `src/connections.ts` validates optional credential references and refuses connector authorization
  when unresolved plaintext-secret exposure is present without an explicit owner exception.
- `scripts/audit.mjs` rejects additional bearer/basic secret-shaped material.
- Tests use only fake labels and an injected fake provider; no credential value is created, read,
  printed or stored.
